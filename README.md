# Hotel De Papae - Hotel Website and Management Portal

ASP.NET MVC web application for **Hotel De Papae**, including public booking pages and an admin portal for property/room operations.

## Overview
End-to-end hotel web platform for guests and staff: room discovery, reservations, content pages, and back-office management screens.

## Key Features
- Public hotel website (rooms, gallery, policies, contact)
- Booking / reservation workflows
- Admin dashboard for property and room management
- Content and media uploads
- SQL Server + Entity Framework data access

## Tech Stack
- **Backend:** ASP.NET MVC (C#), .NET Framework 4.7.x
- **Frontend:** HTML, CSS, JavaScript, jQuery, Bootstrap
- **Database:** Microsoft SQL Server + Entity Framework
- **Hosting:** IIS

## Solution
- `HotelWebSiteMVC.sln`
- `HotelWebSite/` - MVC application

## Getting Started
1. Open `HotelWebSiteMVC.sln` in Visual Studio
2. Update connection strings in `Web.config`
3. Restore NuGet packages
4. Build and run (IIS Express / local IIS)
